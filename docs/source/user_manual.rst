Руководство пользователя (User Manual)
=====================================

Установка и первый запуск
-----------------------------
1. Запустите файл установщика ``DBSchemaVisualizer_Setup.exe``.
2. В появившемся окне мастера установки вы можете выбрать любой удобный путь для размещения программы.
3. По умолчанию инсталлятор предлагает базовый общесистемный путь:
   ``C:\Program Files\DBSchemaVisualizer\``
4. Дождитесь завершения копирования файлов и запустите приложение с помощью ярлыка на Рабочем столе.

Начало работы
-------------
1. **Авторизация**: При старте приложения пройдите регистрацию или войдите под существующей учетной записью.
2. **Создание подключения**: Нажмите кнопку `+ Создать соединение` в левой панели.
3. **Выбор СУБД**:
   * Для **PostgreSQL** введите хост, порт, имя базы данных и данные пользователя.
   * Для **SQLite** укажите путь к файлу базы данных (кавычки будут удалены автоматически).
4. Нажмите `Сохранить`, чтобы профиль зафиксировался в истории и системной папке ``AppData``.

Работа с интерактивным холстом
------------------------------
* **Навигация**: Зажмите левую кнопку мыши на пустом пространстве холста для перемещения (ScrollHand).
* **Горизонтальный скролл**: Зажмите клавишу ``Shift`` и крутите колесико мыши для смещения влево/вправо.
* **Масштабирование**: Зажмите клавишу ``Ctrl`` и крутите колесико мыши для приближения/удаления.
* **Перетаскивание таблиц**: Любую карточку таблицы можно свободно перемещать мышью — линии связей FOREIGN KEY перерисуются автоматически под углами 90 градусов.

Визуальный конструктор запросов
-------------------------------
1. Нажмите кнопку `Параметры` над полем SQL-запроса.
2. Выберите таблицу и поле для вывода (SELECT). Опция ``* [Выбрать все поля]`` автоматически подставит маску выборки для всей таблицы.
3. Добавьте условия фильтрации (WHERE), выберите поля сортировки (ORDER BY) или лимит строк (LIMIT).
4. Нажмите `Добавить правило`, а затем `Применить`.
5. Нажмите `Выполнить` на главной панели для отображения данных в таблице результатов.
